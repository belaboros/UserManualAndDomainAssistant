## 2. Modelling a domain with the generator (afterwards)

**You never edit files. You give statements and read the generated Markdown. I only edit the sources.**

1. **You give a statement**, e.g. *"Each platform service is owned by a platform team."*
2. **I record it word for word** in `statements.yaml` as `S11`, with the date and the current working level.
3. **I turn it into model items** in `ontology.yaml`. Each item cites the statement as its `source`, and any wording that's mine is marked `draft`:
   ```yaml
   relations:
     - {id: ownedBy, label: owned by, domain: PlatformService, range: PlatformTeam,
        cardinality: "1", level: 1, status: confirmed, source: [S3]}
   ```
   If something is ambiguous (how many? which kind?), I ask you, and the question goes into idea 0001's Q&A log.
4. **For every rule I also write sample data**: one valid example and one example that breaks the rule. A derivation rule gets an input sample and the triples it should infer. This proves the rule actually fires.
5. **I run `domain-model build`**. It regenerates every format under `generated/`: OWL in Turtle, RDF/XML and JSON-LD, SKOS, SHACL, TBX, the glossary, the diagrams and `level-1/2/3.md`.
6. **I run `domain-model check`**. It catches broken references, wrong levels, missing samples, rules that don't behave as their samples say, and generated files that are out of date.
7. **You read** `generated/level-1.md` (or `glossary.md` / `diagrams.md`) on GitHub or in a Markdown preview, and correct what I got wrong. When you confirm a `_(draft)_` item, I set it to `confirmed`.
8. **Commit.** Pre-commit runs `check` again, and so does CI. A hand edit to `generated/`, or a forgotten rebuild, is rejected.
9. **When you say "level 1 is complete"**, `working_level` moves to 2, and new items start at level 2.

So a modelling session is a loop: statement → my questions → YAML + samples → build + check → you review the level view. The generated files can't drift from the sources, because `check` re-renders everything and compares it byte for byte.
